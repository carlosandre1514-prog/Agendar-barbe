# Agenda Barba
Site de agendamento de barbearias (GitHub Pages + Supabase).

- index.html        tela inicial (filtro de estado/cidade, busca por nome)
- loja.html         página da barbearia e agendamento
- dono.html         painel do dono (login, resumo do mês, aviso por WhatsApp)
- admin.html        painel do administrador (login, cria barbearia + conta do dono)
- agendamentos.html "Meus agendamentos" do cliente (ver e cancelar)
- redefinir.html    página de redefinir senha (link enviado por e-mail)
- js/comum.js       código compartilhado (Supabase, estilo, login, cache de cidades)
- sql/              scripts do banco (já rodados no Supabase)
- favicon.svg, manifest.json  ícone e instalação como app (PWA)
- robots.txt, sitemap.xml     indexação no Google (troque SEU-DOMINIO no sitemap.xml)
